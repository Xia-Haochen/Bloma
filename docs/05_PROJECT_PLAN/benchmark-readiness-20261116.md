- Windows 11 26200；本机参考配置Ryzen 9 8945HX、16核32线程、约32GB内存。各组实际硬件与Agent版本在run-environment.json登记。

- 每项任务90分钟、制作费用上限10元；所有制作、委派、内部审阅和调试模型费用计入；外部验收费用单列。
