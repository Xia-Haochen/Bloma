# 独立验收的服务与输入语义修复

本次复核对象是 wallet-fresh 试验项目 328c1954-7c68-44c4-ae5e-20371b316fff。其原生界面九项通过，独立验收最后为五项通过、四项未验证、三项未运行。执行记录显示宿主的服务准备和输入选择存在以下冲突。

- 整个功能具有模型能力时，每个案例都被要求发请求。空录音及取消录音明确要求零请求，却收到 REQUEST_NOT_OBSERVED。
- 任意 expect 包含 input/literal 预期，整个案例都被认定为固定模型内容。模型名称、输出上限、保存地址等确定性值因此触发 EXTERNAL_ORACLE_REQUIRED。
- 服务准备统一将模型名改成 bloma-acceptance-text，影响要求 deepseek-flash 的配置断言。
- speech_input 统一上传 voice-golden.wav。原静音案例只给控件取了静音名称，实际输入仍是有声录音。

服务准备现在保存产品已选择的非空模型名，普通配置断言进入实际执行。只有断言失败的实际值包含本次受控回复，并且该断言没有引用先前观察值时，才报告需要独立模型语义证据。重开/历史一致性断言继续比较已观察到的真实值。

独立设计可以声明案例 service.requests 为 none 或 response，source 逐字引用确认预期。none 案例仍准备可观察的服务，实际请求数须为零，发出请求会被拒绝。证据记录请求预期及请求计数。默认 response 保留旧契约解释。

speech_input 可明确声明 sample:silence。宿主冻结并上传两秒、16kHz、单声道PCM16零振幅WAV，有声样例继续使用已有录音。控件名称不决定字节内容。

真实浏览器回归验证零请求取消、错误发请求的反例、保留模型名、固定配置值与实际回复共存、固定生成回复不符的诊断、拒绝静态假回复、有声与静音文件的实际上传和忽略输入的反例。受控环境及独立设计/质量/关联来源整组63项通过，随后补跑有声/静音两个用例通过。typecheck、build:main、docs:check通过。

旧试验的冻结用例及争议记录仍是原试验事实。新字段供独立设计和经过授权的案例修订使用，旧的零请求/静音用例需要经独立设计修正后才能按新语义执行。该批次没有新增付费模型调用，尚未执行新的完整制作到交付试验。
