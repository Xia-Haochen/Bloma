# Agent模拟用户与制作效果测试

## 当前方法：允许正常用户交互，禁止外部工程代修

用户已明确，阶段确认和基于实际效果的意见属于测试需要；理想流程由Agent模拟真实用户测试制作效果。当前采用“模拟用户交互、无外部工程协助”的口径，不再把需求确认作为整个试验不可逾越的终点。原只观察段的结果和费用保持不变。

新增 `prepare-user` 与 `simulate` 两个阶段，沿用 `software-observation-trial.mjs`，不恢复已删除的旧驾驶器。先完成原始需求的run段，停在awaiting_user；prepare-user读取这一边界及原manifest/策略/项目哈希，独立生成user-runtime.json，记录新的模拟用户授权和方法变化，不覆盖原运行包、报告或账本。simulate在同一项目、会话、费用策略和epoch中继续，独占user-run-claimed.json，不能重复启动。制作方和用户代理共用金额保护及累计请求上限；用户代理费用以simulated-user角色单列，原费用不清零。

prepare-user需要 `BLOMA_SIMULATED_USER_AUTHORIZATION_TEXT`，内容来自用户对模拟用户测试的明确指令；其余ROOT/CASES/TASK/THINKING仍与原窗口一致。两段运行分别记录平台/驾驶器版本，方法改变后的结果不能伪装成原方法的零交互续跑。当前仅支持从一个已结束的awaiting_user原始段接续，不自动接管失败/运行中试验。

用户代理只看到原始愿望、公开确认卡、最近用户动作、真实截图、可见文字与控件状态。内部选项ID由宿主映射；不提供源码、测试、日志、账本、任意文件/命令/网络请求或JavaScript执行工具。页面内容视为不可信资料，不作为系统指令。

允许的动作：确认或回答问题、点击、输入、按显示文字选择选项、在画布画线、有界等待、关闭并重开试用、提出普通用户意见、结束评价或明确无法判断。草图必须实际打开截图后才能评审；试用反馈必须绑定当前观察且至少操作过一次，未看过的界面和过期截图不能用于反馈。原始反馈通过需求/UX或制作消息入口送回平台，不直接修改产品；反馈前检查所见候选仍对应当前源码。

界面使用独立浏览器/Electron和合成测试数据，截图与操作保留观察ID和候选来源；普通控件动作不能变成选择器/eval脚本。保存和重开复用同一隔离数据目录。用户评价不是宿主PASS：产品发布、用户体验评价和独立业务验收分别报告。当前代理只具有截图/DOM观察，没有音频测量或听觉能力；不得宣称已听到声音，涂鸦的实际音频效果仍需独立音频验收。

模拟用户最多40步、共享45分钟执行信号和原金额窗口；平台内部修复照常进行。未知卡片、缺少预览、启动失败、无效动作或费用守卫保留失败/未验证，不由外部Agent修代码或放宽条件。不得通过添新功能制造测试需求；正常输入与外部工程干预分开计数。

本轮仅实现与离线验证，尚未用真实供应商运行模拟用户段，也没有改动此前涂鸦项目的状态或0.128699元记录。

验证证据：`run-artifacts/simulated-user-check-final-20261105.log`中类型、docs、前后端构建与11文件75项通过；关闭顺序收敛后，`simulated-user-final-ui-20261105.log`中真实浏览器操作/重开/来源失效及启动接续2文件12项通过，两组重叠不累加。费用与请求记录保护另见`simulated-user-guards-20261105.log`。第一轮完整检查曾为74通过/1失败：反例用例修改源码后未恢复，正常关闭检查再次拒绝；修正测试清理与原始错误断言，未放宽守卫，旧失败日志保留。

本机实测覆盖浏览器控件、画布、保存、真实后台关闭重开、旧候选拒绝、公开输入投影、无任意执行动作、方法接续不覆盖原报告/预算。Electron分支复用既有启动/环境机制，但本批未单独新增真实Electron产品试用证据；供应商模型能否提出有价值的用户意见、端到端生成效果、数字音频/真实听感均不由这些离线结果证明。

## 实现与使用边界

入口为 `scripts/software-observation-trial.mjs`，三个独立命令：`prepare`只编译和冻结代码/模板，`preflight`检查模型目录、余额、人工核对的模型专属报价和金额策略，`run`只向真实向导提交一次原始需求。编译失败不会发布runtime.json；后两步不重新编译。运行前核对代码、模板、思考设置、需求、渠道配置、报价证据和旧账本；独占run-claimed.json防止重复或并发重跑，同轮失败也不释放标记。

此版本将首次需要用户决定作为本段终点，返回原始decision事件，既不代答也不提供续跑命令。尚未实现携带原预算、冻结身份和用户原文的人工回应续段；不能切换到未绑定本轮金额保护的普通实例继续，再算作同一次测试。首次范围确认可能就是新样本终点，不承诺一条命令跨过全部确认完成生产。

配置使用全新的 `BLOMA_OBSERVATION_*` 前缀：ROOT（隔离目录）、CASES（仅一个任务，name/goal必需；兼容旧change字段但不发送）、TASK（任务键）、AUTHORIZED_CAP、AUTHORIZATION_TEXT、THINKING（low/off，冻结后不可改）、QUOTE_FILE。模型固定为既有公开DeepSeek Flash渠道；不继承旧窗口或旧续跑反馈。超时固定45分钟，产品自身的预算与执行守卫保持生效。

QUOTE_FILE为人工核对后保存的JSON，包含host、model、context_tokens、input_rmb_per_million、output_rmb_per_million、cache_rmb_per_million、source_url、source_path、source_sha256、reviewed_at。来源为DeepSeek官方价格页，证据字节须匹配，核对时间不得超过24小时；费率必须按对应模型逐项核对，程序校验格式/身份/时效不等于自动认证报价正确。预检保留价格原文与哈希，不再依赖整页包含几个数字来证明对应关系。

事件、请求轨迹、原始失败、项目与发布状态、usage和金额分别保存。awaiting_user、failed、stopped、incomplete、released_pending_independent_acceptance各自保留含义；独立验收不由驾驶器自动调用。

旧 `software-complex-trial.mjs` 与 `.ts` 已实际删除，所有旧阶段（含preflight/inspect）均无入口。历史脚本片段只供追溯，原始记录器、导出工具、独立验收模块及历史证据继续保留；不恢复旧运行入口来补验。
