## 开始前

1. 建立独立项目、会话、数据目录、预算策略与账本，固定需求原文及不展示给制作模型的独立评价标准。模型、思考、平台、驾驶器、测试规则记录版本/哈希；不复制旧候选或模型会话。
2. 准备、文件/编译校验、离线驾驶器验证、渠道及金额预检、正式启动分开执行。任何准备失败禁止继续启动；不得临时裁剪源码后直接计费。
3. 只观察驾驶器必须离线证明：不会自动确认、追加提示、改代码/测试、重启续跑、刷新预算或因观察到错误自行改变生产状态。观察器只保存记录；既有平台守卫以及预先固定的预算/取消/时限控制独立负责停止。
4. 核对实际渠道、模型、费率、可用余额、未结算责任与完整输入预留。10元授权覆盖同一新样本全部模型请求，不与旧涂鸦窗口合并，也不授权额外样本。当前新样本尚未启动；准备受阻不是生成失败样本。
5. 自动审批拒绝属于外部执行阻断，不能靠拆命令、改工具或换名称绕过。方法改进本身不解除拒绝；执行条件允许且预检完成后才能启动。

## 正式运行

- 第一条模型请求发出后冻结方法和代码。仅记录事件、原始错误、工具输入输出、版本、请求/费用和时间线，不向生产会话注入观察结论。
- 用户确认是独立交互边界。原样呈现平台问题，由用户本人回答；助手不代答、不添加建议。记录用户输入及等待时间，和自主执行时间分开。没有回答则停在待确认，不记成自主失败或跳过确认。
- 平台自身自动修复、协作及宿主验收照常运行并计入本轮。外部观察者不承担它们的工作。
- 自然结束、明确失败、必要用户输入、预算守卫或固定时限分别记录。进程退出码不是交付凭据；失败后不修复、不自动续跑。
