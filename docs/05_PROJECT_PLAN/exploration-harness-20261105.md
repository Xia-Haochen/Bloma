# 探索与实验执行链路

实施起点3561c9e。复用现有Pi、委派、预算与宿主交付机制，新增受管理的独立实验；不新增常驻协调模型，不恢复旧测试驾驶器。

## 当前行为

- 主负责人通过既有delegate_agent传experiment:{criterion,inputs}，task描述关键未知。role使用implement/custom或默认；review/research/explore及显式read_only仍不能取得写入/执行权。inputs为最多32个项目内普通文件，每个最多16MiB、合计32MiB，拒绝越界和依赖/备份目录。
- 实验工作区位于PROMA_HOME/software-experiments/项目/子会话/work，与正式源码、实验数据、宿主回执和封存证据分开。文件工具复用AsyncLocalStorage根覆盖、先读后写和文件版本保护；实验没有正式verify_app、范围变更、能力准备或递归委派工具。
- 实验run_command复用项目命令执行器及清洗后的环境，保留命令、cwd、超时、运行前工作区指纹、退出码、输出或失败，单次最多60秒。委派结束/取消会撤销实验租约并中止在途命令。继承父会话模型与费用边界，不产生新额度。
- 目录和数据隔离用于避免普通工程工作互相覆盖，不是OS安全沙箱。任意程序仍由当前用户执行；不以目录/命令过滤宣称可安全运行敌意代码，不增加系统修改或外发权限。
- 子Agent用record_experiment_result记录method/finding/verdict/artifacts。supports/refutes必须已有实际运行；解释标为agent_claim，永远不签发产品PASS。产物按字节封存；后续写入/运行使当前结论指针失效，历史证据不删除。
- 既有委派交接附简短实验摘要。主负责人read_experiment读取事实、结论和封存代码，按正常文件工具集成，再走原宿主验收。源版本变化会提示重新核对适用性。实验结果可回读，不接管历史PID。
- 有效的新实验结论计入探索进展，相同报告不反复刷新进展；这不是自动判定语义正确。失败仍分类保留，完整目标仍以正式验收为准。
- 组件目录改为可选资源：先查契约是否适用，未知方法可查资料和做实验，组件缺项不作为能力上限。已有存储、队列、HTTP、文档等组件和全部质量/发布约束保留。

## 真实预览观察

Electron预览handler和模拟用户共用resolvePreviewFile：授权项目、realpath根边界、目录入口、资源类型与UTF-8处理。模拟浏览器将bloma-file入口映射到当前上下文的受控请求路由，没有启动额外服务器；相对路径及项目根绝对路径资源均通过同一文件授权。不能读取其它项目或链接越界文件。

这修复视频试验暴露的观察通路缺口；旧试验的失败、四次请求和0.385620元记录保留，未在原冻结样本中偷换实现续跑。
