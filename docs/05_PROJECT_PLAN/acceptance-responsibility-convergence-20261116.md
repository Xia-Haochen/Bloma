# 制作、验证和收尾职责收敛（2026-11-16）

基于 `c35be76` 的 Codex 侧变更。用户批准的是收敛宿主职责、减少制作方协议负担，同时保持原需求和验收标准。本批不重开付费语音实验，不修改历史实验结果。

## 问题和边界

此前独立案例准备能挡住制作开始，正常测试维护要由制作方另外提交修订协议，单项缺陷关闭又依赖整轮通过。三者组合会把验收工程问题反复送回业务实现循环。单纯放大重试次数不能消除这种耦合。

本批保持现有 software-v1 状态和工具，调整现有职责，不另建一套审批流程。

| 责任 | 制作方 | 宿主 |
| --- | --- | --- |
| 开始实现 | 按已确认业务目标实现 | 首次候选验证时准备独立案例；显式重设计仍单独处理 |
| 程序和测试维护 | 修改程序或测试，调用 verify_app | 自动沿用登记入口；适配按规则登记，超出适配范围的修订自动封存、隔离执行和独立裁定 |
| 验证反馈 | 查看每项需求结果及具体失败 | 汇总同一候选的 core/independent 证据和下一处理方；明细仍保留在绑定报告中 |
| 缺陷关闭 | 修复后复验 | 按精确案例、环境、规则和当前版本关闭，不等待不相干检查全部通过 |
| 验收准备缺失 | 保留业务实现 | 本机和启动通过时保留试用能力，整体仍为未验证；收尾明确停在宿主准备项 |
| 重试 | 根据现场进行修复 | 同源码、同失败才累计原样重跑；真实版本变化给修复机会，仍共享原费用和时间预算 |
| 正式完成 | 结束制作 | 继续现有必要的代码/视觉审阅、版本校验与发布 |

需求汇总是同一份执行回执的投影，不是新增的独立判官。代码/视觉审阅保留其结构和体验审查职责，本批没有声称用自动案例替代全部质量判断。`next_owner` 表示下一步处理归属，不是已经证明的根因。

## 保留的证据约束

- 业务预期来自已确认要求；修改定位不等于允许降低断言。超出适配规则仍经独立裁定，批准之后仍须正式执行。
- 当前候选、测试字节、服务配置及运行环境持续绑定；取消、输入变化和完整性失败不能生成当前需求通过状态。
- 一个实际失败仍然保留为失败；不完整执行不能关闭缺陷。独立案例换服务配置，不能关闭旧环境下的失败。
- 可试用不等于正式交付；试用继续使用隔离数据和候选绑定。
- 固定音频、模拟服务和受控模型回归不证明真实 ASR、实体麦克风、供应商生成质量、干净机器安装或付费自主完成率。

## 验证方法

关键链使用真实本机进程/浏览器和受控模型响应，记录方法而非宣称付费模型成功：

1. 制作先进入 A，首次 verify_app 才进入独立设计 B；没有候选时 B 配置缺失不阻止制作开始。
2. 浏览器测试先真实读错产品文件；只修复文件路径，再 verify_app。宿主自动提交修订、实际隔离执行、独立裁定和正式复验。制作方没有另调 propose_test_correction。
3. 命令行程序实际输出 999，受控制作方收到失败、读取代码及确认目标、修为 5、复验；宿主继续审阅并完成交付。
4. 同一独立案例实际暴露跨对象破坏或渲染错误，修复后用相同案例验证关闭；其他检查未完成不再阻止该单项关闭。
5. 独立设计未准备时，本机检查和正常启动证据仍保留，隔离试用可运行，项目不能被标成完成。
6. 覆盖原样重跑、源码修订、规则/环境变化、取消和历史通过失效等反例。

本批共核对 12 个测试文件、197 个用例（分组执行，失败项修正后定向复跑；自动修订用例扩为批准/拒绝两个分支）。包括 independent-design、independent-quality、verification-tool、requirement-assessment、long-task-recovery、native-gui-tests、test-corrections、quality-settlement、quality-closeout、feedback-contract、production-tool-assembly 和 observation-trial。类型检查、文档检查、完整构建及最终主进程重建通过。

中间结果不当作通过：旧的前置设计门和三次停止断言已按新/现有行为校准；试用 fixture 补齐目标确认。两项执行遇到修改中的宿主输入变化后被拒绝，固定源码后复跑通过。测试执行期间应固定宿主源码和构建产物；宿主版本变化会主动使运行中的验证回执失效。

## 下一轮真实实验

保持冻结的普通用户输入和外部评分标准，不向制作方注入评分细则。固定本批宿主构建后，再从全新项目观察 DeepSeek Flash / high 的实际调用序列、修复后复验、重复错误、人工介入、耗时和费用。仍需遵守同一钱包账本与完整输入预留，不能重置历史消费换取请求放行。
