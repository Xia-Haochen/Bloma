## W3 产品来源、纠正和派生失效

- `provenance`作为可选基础组件接入既有能力目录、准备工具和上下文；复用product_store，不建立平台个人记忆库，也不固定领域规则或UI。
- source保留稳定身份；capture记录源版本；publish只接受inference/creative，拒绝过期来源、循环、取消后结果。纠正源或派生结果时，所有关联下游在同一事务标stale；current排除过期内容。
- 删除有依赖来源默认拒绝，明确cascade才连同内部派生记录删除。不删除外部原文件、备份或导出；生成应用须根据用户范围处理这些边界，不能宣称全局遗忘。
