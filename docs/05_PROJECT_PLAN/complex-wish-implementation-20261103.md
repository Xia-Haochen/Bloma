## 完成语义

- Task与模型会话结束不等于交付。只有宿主完成路径在同目标、同源码和真实报告下记录verified；发布仍走原候选完整性和质量门。
- 阶段检查是累计局部GUI检查，不覆盖正式完整GUI套件，也不发布生产版本。`stage_checked_test_data`只表示该快照的局部检查和隔离试用，界面和反馈均明确整体未验收。
- 阶段顺序沿确认计划数组推进，所有较早阶段案例在后续检查中保留。本批没有引入自由重排的并行DAG。CLI和其他运行时继续原完整目标执行/验收，不伪造局部GUI阶段通过。
- 普通继续恢复原Pi会话；显式转交保留原用量与记录。旧执行归属被隔离，不能通过转交重复使用旧卡或用新会话获得新额度。
- 推理配置、委派、并发与权限/费用分开观察。现有模型配置保存仍在运行中锁定；未新增热切换或额外默认并发。请求准备记录中的供应商采纳情况保持unknown。
- B的跨功能引用只扩充可追溯规则来源，不把一个案例自动算作多个功能已覆盖。原生GUI可执行复杂业务计算；未明确的B业务预期继续作为争议处理，不猜规则过关。
