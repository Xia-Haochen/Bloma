# 校准范围与正反例

评分标准、公开输入和外部操作脚本按本包版本固定。任务分值均为100，mandatory 项全部通过才算完整完成。

## 已实际执行的校准

- 自动数值/事实核对器对三项任务执行18项正反控制及真实HTTP服务检查，见calibration/results.json。
- 器材正例固定库存与关联，错误反例分别修改可借量、逾期成员和导入后归还结果，均被拒绝。
- 文档正例固定文件、来源和所选事实，错误反例删除重名文件、改错页码、篡改输入摘要和混入未选预算，均被拒绝。
- 语音观察正例包含三轮完整播放和四项回忆事实，错误反例截断音频、静音和遗漏上下文，均被拒绝。
- 受控服务实际HTTP检查覆盖正常请求、401、单次503后恢复、SSE结束及日志凭据去除。
- 中文PDF输入由独立解析器提取并逐行核对。语音输入在评测前由独立VITS工具合成，保存来源和时长。
- 外部计分器另行测试了证据篡改、重复项、跨快照、人工帮助、超时和费用缺失。

自动核对器的正例是明确标注的参考数据，不能充当某个参赛成品已通过的证据。表格中的 UI 操作、设备录音、真实模型语义及录音试听仍需要组员实际执行。包内不包含三个完整业务应用的参考成品，也不宣称已经校准所有产品环境。

## 人工正反例判据

| 检查类别 | 正例 | 反例或未验证 |
| --- | --- | --- |
| 语音转写 | 固定录音的公开事实与实体录音均正确出现 | 仅显示固定文本；导入成功但实体录音未执行时该项未验证 |
| 上下文 | 第三轮准确说出语音助手、周五、300元、蓝色，服务请求含历史 | 固定回复碰巧含一个关键词；遗漏当前发言 |
| 完整朗读 | 对应文本的整段声音可听到自然结束 | 播放标签变完成但中途停止，或音频与当前气泡无关 |
| 空录音/取消 | 无新消息和服务请求，之后正常说话成功 | 将空输入当作有效句子，取消后仍发请求 |
| 设置和记录重启 | 全部产品进程结束后重新启动，读回并继续成功 | 只刷新页面；测试重开前重新注入设置 |
| 跨对象业务 | 所有成员、器材、数量逐项对应 | 总数正确但成员归属错误 |
| 异常原子性 | 失败前后账目一致，合法操作可继续 | 已扣库存却未保存明细 |
| 导入导出 | 新空实例能恢复完整账目 | 导出文件存在但缺借还明细 |
| 来源检索 | 正确相对文件身份和页/行，可打开对应片段 | 重名文件覆盖；返回关键词但位置错误 |
| 文档语义 | 所选事实准确、来源可核对 | 混入未选文档旧预算；引用无法对应 |
| 队列取消/恢复 | 取消指定排队项，其他任务继续，失败项可重试 | 停止整个队列；失败状态直接改成功 |
| 可使用性 | 交付入口及操作路径可由普通用户完成 | 需要操作者手改源码或补写开发命令 |

两名评判者先对本表独立分类，记录分歧，再开始实际成品评分。分歧未解决的检查标 unverified。任何调整判据都应发布新包版本并对所有系统同样应用。

## 发布状态

本版冻结的是输入、评分和可执行的外部核对程序。整体任务采用“自动核对＋人工用户旅程”的混合验收。完成全部人工记录之前，计分工具不会自动补足缺失分数。完整参考成品的跨环境认证仍属于后续校准工作，因此本版ranking_enabled=false，可用于统一采集和pilot诊断，正式研究排名须完成该项校准后发布新版本。
