# 器材借还外部验收

公开日期基准为2026-11-16，逾期查询支持按指定基准日筛选，借出与应还日期可在正常表单中填写。以借还明细计算库存，逾期为应还日早于基准日且未还量大于零。

| 检查 | 外部操作与预期 |
| --- | --- |
| B1 | 从空实例导入 equipment.csv 与 members.csv。修改E03名称为“便携示波器”，E01/E02不变。尝试新增E01必须提示重复。 |
| B2 | M01借E01两件、E02一件；M02借E01一件、E03一件。四笔应还日分别为11-15、11-20、11-20、11-15。M01归还E01一件。E01/E02/E03未还量为2/1/1，可借量为3/2/1。 |
| B3 | M01未还E01一件、E02一件；M02未还E01一件、E03一件。逾期只有M01-E01一件和M02-E03一件。筛选与导出对应同一明细。 |
| R1 | 尝试再借E03两件、对M01-E02归还两件、借入负数。每次均拒绝且前后账目一致。随后M02归还E03一件成功。 |
| R2 | 导入equipment-invalid.csv，错误行和重复编号可定位。选择取消后现有账本完整。使用equipment-extra.csv重试，E04增加成功，E01到E03及借还记录完整。 |
| P1 | 关闭全部产品进程重开。当前未还E01/E02/E03为2/1/0，E04可借量为4，其他配置和记录完整。 |
| P2 | 导出全部业务CSV，在新空数据实例导入。验证所有器材、成员、借还记录及状态等价。再对M02-E01归还一件，E01可借量变成4。 |
| U1 | 按交付说明启动，并通过界面完成全部操作。 |
| U2 | 在录屏中确认目标成员/器材、数量单位、过滤条件、错误和成功状态均可辨认。 |

在每个检查后拍摄状态及明细，并保存原始导出文件。填写 equipment-facts.json 时从界面及导出独立提取，记录对应录屏时间。自动核对器检查B2/B3/P1/P2的数字；R1/R2和UI路径需人工逐步记录。总量在所有操作中始终为E01=5、E02=3、E03=2、E04=4。

CSV备份可以由多个文件组成，允许产品自行定义内部文件名。公开输入列定义随输入目录提供。验收不要求内部数据库结构。
