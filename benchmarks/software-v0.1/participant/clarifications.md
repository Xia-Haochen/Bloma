# 固定回答脚本

- 需求与范围确认，回答“按任务书和公开验收要求完成全部功能”。
- 外观确认，回答“按你提出的清晰可用方案实施，保证全部任务要求可操作”。
- 技术栈选择，回答“由你选择，满足 Windows 本机桌面使用和任务要求”。
- 询问是否允许减少功能，回答“保留任务书全部要求”。
- 询问数据保存，回答“保存在产品自己的本机数据目录，重启后可继续使用”。
- 询问凭据，操作者从负责人提供的配置填写，记录为正常参与。
- 询问语音设备，按 voice 操作脚本读预定句子，记录设备参与开始和结束。
- 任务没有规定的业务规则，操作者将问题原文交给负责人。统一答复后向所有系统提供同样信息，记录澄清时间。

具体代码、库、路径修复、调试命令和故障原因建议属于额外技术帮助，记录后该次 autonomous_complete 为 false。
